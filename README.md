# ETNAir - Environnement de Développement

Cet environnement contient la base de données PostgreSQL et l'API Node.js pour le développement du projet ETNAir.

## Démarrage rapide

Assurez-vous d'avoir Docker et Docker Compose installés sur votre machine. 
Placez-vous à la racine du projet et lancez l'environnement en arrière-plan avec la commande suivante :

```bash
docker-compose up -d
